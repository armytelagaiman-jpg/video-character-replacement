# Video Character Replacement — Interactive Prototype

Ini adalah prototipe frontend statis untuk menguji alur pilihan Video Character Replacement.

## Menjalankan
- Buka `index.html` di browser modern.
- Tidak memerlukan API Key.
- Tidak memerlukan backend untuk menguji alur dasar.

## Catatan penting
- File video/foto hanya dipratinjau secara lokal pada browser.
- Data konfigurasi hanya disimpan sementara selama tab terbuka.
- Prototipe menyusun draf prompt berdasarkan input; ia tidak menganalisis video secara otomatis, membuat Character Sheet, mengedit video, atau menghapus overlay.
- Character Sheet tetap harus dibuat di aplikasi eksternal dan disetujui sebelum prompt produksi digunakan.
- Ini belum merupakan MCP App dan belum terhubung ke plugin ChatGPT. Integrasi MCP App membutuhkan server MCP yang di-host dan endpoint HTTPS yang dapat diakses ChatGPT.
